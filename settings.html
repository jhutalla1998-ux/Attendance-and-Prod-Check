About IMS

Information about the Inventory Management System.

How it Works

The Inventory Management System (IMS) is a comprehensive tool designed to streamline daily inventory operations. It integrates attendance tracking, cycle counting, and validation tasks into a unified dashboard.

  • Attendance: Track daily attendance for IC teams, manage shifts, and monitor live status.
  • Cycle Counting: Record and monitor daily cycle counts, track productivity against targets, and generate hourly output reports.
  • Validation: Assign and track validation tasks, monitor validator performance, and ensure inventory accuracy.
  • Analytics: Visualize performance trends, identify top performers, and generate detailed reports for decision making.

Benefits

  • Real-time Visibility: Monitor operations as they happen with live dashboards and hourly updates.
  • Improved Accuracy: Reduce errors through systematic validation and automated tracking.
  • Enhanced Productivity: Set targets, track performance, and identify areas for improvement.
  • Data-Driven Decisions: Utilize comprehensive analytics and reports to optimize resource allocation.

Timestamp (Daily Cycle Count)

Track active counting time and productivity.

🖼️

[Insert Screenshot of Timestamp Modal Here]

  1. Go to Daily Cycle Count > Timestamp (or sidebar shortcut).
  2. Enter User ID (must be in Attendance).
  3. Click Start Counting. Select Area (Pick/Reserved) if prompted.
  4. Use Break Out / Break In for breaks.
  5. Click End Counting when done. Input Pallets and SKUs to log performance.
Validators View (All IC Attendance)

Assign and manage validation tasks.

🖼️

[Insert Screenshot of Validators View Here]

  1. Go to All IC Attendance > Validators View.
  2. Click Add Task (or floating button) to create a validation request.
  3. Assign tasks to specific validators or leave as Unassigned (Pending).
  4. Track progress in Assigned and Resolved tabs.
  5. Validators mark tasks as Resolved (with findings) or Unresolved.
